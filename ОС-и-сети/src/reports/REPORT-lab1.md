# Отчёт: Лабораторная работа №1 — Основы Bash и Linux

## ТЗ (что нужно было сделать по сути)
Освоить работу в терминале Linux: перенаправление вывода, фоновые процессы, пайпы, права доступа, написание простых bash-скриптов.
1. Запустить скрипт в фоновом режиме (`&`), познакомиться с `cat`, `clear`, `wc`.
2. Отфильтровать строки текстового файла с помощью `grep` и пайпов, сохранить результат в новый файл; сделать команду `rm` «бесшумной», перенаправив её вывод в `/dev/null`.
3. Сделать `hello.sh` исполняемым через `chmod +x`; написать свой скрипт, печатающий текущую директорию (`pwd`), дату (`date`) и переменную окружения `PATH`.
4* (со звёздочкой). Написать `average.sh`, считающий среднее арифметическое переданных аргументов; сгенерировать файл из 150 случайных чисел и передать их скрипту.

## Как реализовано

### Задание 1 — фон, cat/clear/wc
```bash
./background.sh &        # запуск в фоне, shell сразу возвращает приглашение
cat cake_rhymes.txt      # вывод файла
wc -l cake_rhymes.txt    # подсчёт строк
clear                    # очистка терминала
```

### Задание 2 — grep, пайпы, /dev/null
```bash
grep 'cake' cake_rhymes.txt | grep -v 'lie' > filtered.txt   # цепочка фильтров
rm somefile 2>&1 > /dev/null                                 # «бесшумное» удаление
```
Разбор: первый `grep` оставляет строки со словом *cake*, второй отбрасывает строки со словом *lie*, `>` перезаписывает результат в `filtered.txt`. `2>&1 > /dev/null` направляет stderr в stdout (который уже перенаправляется в «чёрную дыру») — ошибки не видны.

### Задание 3 — права доступа и скрипт info.sh
```bash
chmod +x hello.sh
```
Создан `lab1/src/info.sh`:
```bash
#!/bin/bash
echo "Current directory: $(pwd)"
echo "Current date:      $(date)"
echo "PATH: $PATH"
```

### Задание 4 — average.sh и генерация случайных чисел
Создан `lab1/src/average.sh`:
```bash
#!/bin/bash
sum=0; count=0
for n in "$@"; do sum=$(echo "$sum + $n" | bc); count=$((count+1)); done
if [ $count -eq 0 ]; then echo "No arguments"; exit 1; fi
echo "scale=2; $sum / $count" | bc
```
Генерация 150 случайных чисел и запуск:
```bash
od -An -N600 -tu4 /dev/urandom | tr -s ' \n' '\n\n' | grep . | head -150 > nums.txt
./average.sh $(cat nums.txt)
```
(Вместо `/dev/random`, который блокируется при нехватке энтропии, использован его неблокирующий аналог `/dev/urandom`.)

## Проверка
- `info.sh` выводит корректные pwd/date/PATH;
- `average.sh` на наборе `1 2 3 4` даёт `2.50`, на 150 случайных числах — правдоподобное среднее;
- `filtered.txt` содержит только нужные строки; `rm` без сообщений об ошибках.

Освоены механизмы POSIX-оболочки: конвейеры, три стандартных потока (stdin/stdout/stderr, файловые дескрипторы 0/1/2), фоновое выполнение, биты прав `chmod` и базовое программирование на bash.
