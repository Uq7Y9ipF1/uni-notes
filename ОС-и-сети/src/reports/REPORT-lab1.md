# Отчёт: Лабораторная работа №1 — Основы Bash и Linux

## ТЗ (что нужно было сделать по сути)
1. Запустить скрипт в фоновом режиме (`&`), поработать с `cat`, `clear`, `wc`.
2. Отфильтровать строки файла пайпом `grep`, сохранить в новый файл; сделать `rm` бесшумным (вывод в `/dev/null`).
3. Сделать `hello.sh` исполняемым (`chmod +x`); написать свой скрипт с `pwd`, `date`, `$PATH`.
4* (со звёздочкой). `average.sh` — среднее арифметическое переданных аргументов; сгенерировать 150 случайных чисел из `/dev/random` и передать их скрипту.

## Что нужно знать

### Архитектурный уровень
- **Процесс = программа + состояние.** Bash — обычный пользовательский процесс; каждая команда без `&` запускается как дочерний (`fork()`+`execve()`) и родитель ждёт её. `&` отключает ожидание (job control, PID доступен как `$!`).
- **Дескрипторы и редиректы.** У процесса открыты fd 0/1/2 (stdin/stdout/stderr). Пайп `a | b` — системный вызов `pipe()`: ядро создаёт кольцевой буфер, stdout первого подключается к концу записи, stdin второго — к концу чтения. Перенаправления `>`, `>>`, `2>&1` реализованы через `dup2()` до `exec`.
- **`/dev/null`** — символьное устройство-поглотитель: записьотбрасывается, чтение даёт EOF. Заглушка ошибок: `cmd 2>/dev/null`.
- **Права доступа.** Inode хранит rwx для owner/group/other; скрипту нужен бит `x`, а shebang `#!/bin/bash` указывает ядру интерпретатор при execve.

### Прикладной уровень
- `grep [-i] [-v] [-c] шаблон файл` — фильтрация строк; `wc -l/-w/-c` — счёт строк/слов/байт; `cat` — печать/слияние; `clear` — очистка экрана.
- Внутри скрипта: `$@` — все аргументы, `$#` — их количество, `$VAR` — переменные окружения.
- Случайные числа: `od -An -N150 -tu1 /dev/urandom` (150 байт как беззнаковые числа).

## Реализация
- `lab1/src/background.sh` — фоновый запуск (`sleep &`, `echo $!`, `jobs`, `wait`).
- Фильтрация: `grep -i "the" cake_rhymes.txt > filtered.txt`.
- Бесшумное удаление: `rm -f no_such_file 2>/dev/null`.
- `lab1/src/hello.sh` — сделан исполняемым.
- `lab1/src/info.sh` — мой скрипт: печатает `pwd`, `date`, `$PATH`.
- `lab1/src/average.sh` — среднее аргументов (подсчёт в awk), проверен на 150 случайных числах.

## Команды
```bash
cd lab1/src

# Задание 1
./background.sh
cat cake_rhymes.txt | wc -l
clear

# Задание 2
grep -i "the" cake_rhymes.txt > filtered.txt
wc -l filtered.txt
rm -f no_such_file 2>/dev/null

# Задание 3
chmod +x hello.sh info.sh
./info.sh

# Задание 4*
chmod +x average.sh
./average.sh 1 2 3 4 5                 # -> 3
nums=$(od -An -N150 -tu1 /dev/urandom | tr -s ' \n' ' ')
./average.sh $nums
```

## Проверка
- Фоновая команда сразу возвращает управление, PID виден, `wait` дожидается завершения.
- `filtered.txt` короче оригинала и содержит только подходящие строки.
- `info.sh` печатает корректные директорию/дату/PATH.
- `average.sh 1 2 3 4 5` → `3`; на 150 числах значение совпадает с контрольным подсчётом.
