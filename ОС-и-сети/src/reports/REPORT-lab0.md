# Отчёт: Лабораторная работа №0 — Вводная (настройка окружения)

## ТЗ (что нужно было сделать по сути)
1. Зарегистрироваться на GitHub, создать fork репозитория курса `os_lab_2019`.
2. Освоить среду разработки (Codenvy/Cloud IDE или локальный Linux + терминал).
3. Отработать базовые файловые утилиты: `mkdir`, `touch`, `cp`, `mv`.
4. Запустить `update.sh` (установка утилит), скомпилировать и запустить программу на C через `gcc`.
5. Закоммитить новые файлы (`empty`, `newhello.c`) в свой форк.

## Что нужно знать

### Архитектурный уровень
- **Git — распределённая VCS.** Форк — полный серверный клон; рабочий процесс: рабочее дерево → staging (`git add`) → коммит (снапшот дерева blob-объектов с указателем на родителя) → `git push` в `origin`.
- **Конвейер сборки C:** препроцессор (`cpp`: `#include`, макросы) → компилятор (C → ассемблер) → ассемблер (`.s` → `.o`) → линковщик (`ld`: `.o` + библиотеки → ELF).
- **ELF-запуск:** ядро отображает сегменты кода/данных в адресное пространство нового процесса, точка входа `_start` → `main`.

### Прикладной уровень
- `mkdir`, `touch empty`, `cp src dst`, `mv a b` — базовые операции файловой системы.
- Git отслеживает содержимое файлов; пустой файл коммитится как blob нулевой длины.
- `gcc file.c -o app` собирает бинарник; запуск `./app` (`.` обязателен — текущая директория не в PATH).

## Реализация
- Создана структура `lab0/hello/`, туда скопирован `hello.c` → `newhello.c`, создан `empty`.
- Выполнен `update.sh`, установлена цепочка gcc. Скриншоты — в `lab0/text/pics/`.

## Команды
```bash
cd lab0
mkdir hello && touch empty
cp src/hello.c hello/newhello.c
sh update.sh                      # установка утилит окружения
cd hello
gcc newhello.c -o newhello_app
./newhello_app                    # вывод изменённого приветствия
git add empty newhello.c
git commit -m "lab0" && git push origin master
```

## Проверка
Компиляция без ошибок, `./newhello_app` выводит изменённую строку. Файлы `empty` и `newhello.c` присутствуют в истории коммитов форка (скриншоты `fork_done.png`, `gcc_version.png`).

Освоены базовые операции Linux, цикл git fork→change→commit→push и конвейер сборки C — фундамент для всех последующих лабораторных.
