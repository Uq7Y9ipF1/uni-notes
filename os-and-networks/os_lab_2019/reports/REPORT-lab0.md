# Отчёт: Лабораторная работа №0 — Вводная (настройка окружения)

## ТЗ (что нужно было сделать по сути)
Познакомиться с инструментами курса: GitHub, облачная среда Codenvy, терминал Linux, компилятор `gcc`.
1. Зарегистрироваться на GitHub и в Codenvy, сделать fork репозитория курса `os_lab_2019`, склонировать его к себе.
2. Попрактиковаться с базовыми утилитами файловой системы:
   - создать директорию `hello` внутри `lab0` (`mkdir`);
   - скопировать в неё файл `hello.c` (`cp`);
   - переименовать/переместить его в `newhello.c` (`mv`).
3. Запустить скрипт `update.sh` (установка вспомогательных утилит).
4. Скомпилировать `newhello.c` через `gcc`, запустить получившийся бинарник.
5. Создать пустой файл `empty`, закоммитить все новые файлы и запушить в свой репозиторий на GitHub.

## Как реализовано
Все действия выполнены в терминале Linux:

```bash
cd lab0
mkdir hello                       # создали директорию hello
cp hello.c hello/                 # скопировали исходник туда
mv hello/hello.c hello/newhello.c # переименовали в newhello.c
bash ../update.sh                 # установка утилит окружения
gcc hello/newhello.c -o hello/newhello   # компиляция
./hello/newhello                  # запуск -> выводит "Hello, World!"
touch empty                       # пустой файл для проверки git
git add . && git commit -m "lab0" && git push
```

Результат работы программы:
```
Hello, World!
```

## Проверка
- `newhello.c` присутствует в `lab0/hello/`, собирается без ошибок, печатает приветствие;
- файл `empty` создан и отслеживается git;
- изменения отправлены в форк репозитория на GitHub.

## Вывод
Окружение настроено: освоены clone/fork/commit/push в Git, базовые файловые утилиты shell и цикл «написал → скомпилировал gcc → запустил».
